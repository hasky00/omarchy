# Hasky Note

Fast terminal notes for Omarchy. Plain markdown files in `~/notes`, themed by your current Omarchy theme.

## Install

On Hasky Omarchy, pick **Install > Hasky Labs > Hasky Note** in the Omarchy menu, or run:

```bash
omarchy install hasky-note
```

Then press **Super + Shift + Alt + N**, or find Hasky Note in the app launcher.

On macOS, run `./install.sh` for the command alone.

## Use

```bash
hasky-note                  # open the note browser
hasky-note buy oat milk     # quick capture to ~/notes/inbox.md
```

| Key | Action |
| --- | --- |
| `j` / `k` | move |
| `enter` | edit in nvim |
| `n` | new note |
| `c` | quick capture |
| `/` | search names and content |
| `d` | move to `~/notes/.trash` |
| `q` | quit |

Set `HASKY_NOTE_DIR` to use a different folder.
